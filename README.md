# Blood-Transport-Game
A simulation game for learning double circulation.
(Age: Secondary 4-6 / Grade 10-12.)
#Play Here:
Blood-Transport-Game.github.io
#How to Play:
#Player moves between organs and perform different actions. The goal is to keep the body oxygenated and remove any carbon dioxide and urea.
#Player may perform more than one action at each organ.
#After visiting all body organs (brain, small intestine, liver, kidney), click "Finish Journey" to review the status of the body.
